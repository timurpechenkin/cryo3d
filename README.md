# Cryo3D (alpha)

Cryo3D --- трёхмерная модель промерзания грунта.

Текущая версия поддерживает:

-   виртуальную тензорную сетку (`VirtualGrid`)
-   материалы с фазовыми параметрами
-   температурные поля
-   граничные условия
-   вертикальные профили (разрезы)
-   точки измерения
-   вывод диагностики (`summary.json`, CSV профилей)

------------------------------------------------------------------------

# 📐 1. Система координат

Расчётная область дискретизируется трёхмерной структурированной ортогональной сеткой, построенной как декартово произведение одномерных разбиений по осям X, Y и Z. Шаг сетки может изменяться по каждой оси кусочно-равномерно, задавая локальное сгущение ячеек.

## Расчётная область

Для трёхмерной сети используется правая декартова система координат (x,y,z):

| Ось | Направление |
|:---:|:-----------:|
|  X  |    вправо   |
|  Y  |    вдоль    |
|  Z  |     вниз    |

-   `(0,0,0)` --- верхний левый передний угол модели\
-   все координаты неотрицательные\
-   ось **Z направлена вниз**

## Сторона расчётной области

Для сторон рачётной области (двумерных сеток) используется декартова система координат (w,h):

| Грань | Ширина (w) | Высота (h) |
|:-----:|:----------:|:----------:|
|  X_*  |      Y     |      Z     |
|  Y_*  |      X     |      Z     |
|  Z_*  |      X     |      Y     |

------------------------------------------------------------------------

# 🧮 2. Внутренние числовые конвенции

Cryo3D использует фиксированную точку `int` вместо `double` внутри сетки.

    SCALED  = meters * 100
    SCALED2 = meters * 100 * 2

  Что хранится             Масштаб
  ------------------------ ---------
  границы ячеек (edges)    SCALE
  шаги ячеек (steps)       SCALE
  центры ячеек (centers)   SCALED2

------------------------------------------------------------------------

# 📦 3. Формат `case.yaml`

Все координаты задаются в **метрах**.

## ⏱ Время

``` yaml
time:
  dtSeconds: 3600
  saveEverySeconds: 21600
  totalSeconds: 604800
```

## 🧱 Сетка

Поддерживается только `VirtualGrid`: трёхмерная структурированная ортогональная сетка с неравномерным шагом вдоль координатных осей.

``` yaml
grid:
  axes:
    X:
      - from: 0.0
        to: 10.0
        step: 1.0
```

## 🌡 Граничные условия

Типы:

-   FIRST_KIND
-   SECOND_KIND
-   THIRD_KIND

В текущей версии вся грань покрывается одним граничным условием.

## 🪨 Материалы

Параметры:

-   теплопроводность (талый / мерзлый)
-   теплоёмкость (талый / мерзлый)
-   скрытая теплота фазового перехода
-   температура замерзания

Правила применяются последовательно. Последнее совпавшее правило
побеждает.

## 🌡 Температура

Поддерживается только тип:

    CONSTANT

## 📏 Профили

Профиль --- вертикальный разрез вдоль AB.

-   строится по центрам ячеек
-   Z направлена вниз

## 📍 Точки измерения

В этих точках будет сохраняться температура на каждом шаге расчёта.

# 📊 5. Индексация массивов

## 3D поля

    idx = x + nx * (y + ny * z)

## 2D грани

    idx = w + width * h

# 🏗 6. Архитектура

DTO → Resolver → Domain → Discretizer → Fields → Output

------------------------------------------------------------------------

# ⚠ Ограничения

-   Только VirtualGrid
-   Только CONSTANT температура
-   Нет двумерных BC правил
-   Нет DXF-импорта
-   Нет энтальпийного метода
